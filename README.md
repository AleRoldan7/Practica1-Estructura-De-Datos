# Practica1-Estructura-De-Datos

##Descripcion

En la siguiente practica se desarrollo el juego de UNO y UNO FLIP como expansión del juego utilizando el lenguaje de programación c++ en su versión de consola que es la forma en la que se vera el juego, se utilizaron listas
enlazadas, pilas y listas doblemente circulares. 

Les dejo las instrucciones para poder compilar y ejecutar el juego en consola, ya cuenta con el ejecutable así que no sera problema crearlo. 

##Requisitos

CMake 3.1 o superior
Compilador C++ (GCC / MinGW / MSVC)

##Instrucciones de compilacion

Clona el repositorio en donde desees : git clone https://github.com/AleRoldan7/Practica1-Estructura-De-Datos.git

##Compilar en Linux
Luego dirijete a la carpeta donde lo clonaste encontraras una carpeta que se llama Uno entra ahí y encontraras otra carpeta que se llama build que es donde se encuentra el ejecutable.
En la terminal ejecuta la siguiente línea de codigo para ejecutar el archivo del ejecutable: ./Uno
De esta manera podras acceder al juego desde la terminal

Compilar en Windows
Luego dirijete a la carpeta donde lo clonaste encontraras una carpeta que se llama Uno entra ahí y encontraras otra carpeta que se llama build que es donde se encuentra el ejecutable.
En la terminal ejecuta la siguiente línea de codigo para ejecutar el archivo del ejecutable: ./Uno.exe
De esta manera podras acceder al juego desde la terminal.
